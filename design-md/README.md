# DESIGN.md collection

Brand design-system descriptions from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (see `LICENSE`).

To have a coding agent build UI in a given style, copy that brand's `DESIGN.md` to the project root (or point the agent at it), e.g. `cp design-md/linear.app/DESIGN.md ./DESIGN.md`.
